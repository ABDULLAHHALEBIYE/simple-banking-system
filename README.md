# 🏦 Simple Banking System (CLI in Python)

This is a simple command-line banking system built with Python. It allows basic user management and money transfers between accounts. This project is part of my learning journey and portfolio to demonstrate my skills in Python programming.

## 🚀 Features

- Display all users and their balances
- Add new users with an initial balance
- Delete existing users
- Transfer money from one user to another
- Input validation and error handling
- Menu-based interface using Python's `match-case` (Python 3.10+)

## 🧠 Skills Demonstrated

- Working with dictionaries in Python
- Using loops and control flow effectively
- Input handling and validation
- Structuring a console-based application
- Using modern Python features like `match-case`

## 📦 Requirements

- Python 3.10 or higher (for `match-case`)

## 🛠 How to Run

1. Clone the repository or download the `.py` file.
2. Open a terminal or command prompt.
3. Run the program:

```bash
python banking_system.py
